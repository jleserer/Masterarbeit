PROJECT STRUCTURE:
==================

├── 📄 data_preparation.py          ← Data loading & 65%-15%-20% split (GOODFELLOW)
├── 🧠 lstm_model.py                ← LSTM implementation (128→64 units)

KEY PARAMETERS:
===============

BOTH MODELS:
  🔹 Data Split: 65% Train | 15% Val | 20% Test (Goodfellow)
  🔹 Loopback Window: L=60 (feature: Close)
  🔹 Batch Size: 32
  🔹 Epochs: 100 (with Early Stopping)
  🔹 Learning Rate: 0.001 (Adam)
  🔹 Dropout: 0.2

LSTM:
  🔹 Layers: LSTM(128) → LSTM(64) → Dense(32) → Dense(1)
  🔹 Parameters: 118,081
  🔹 Strength: Captures temporal dependencies

CNN:
  🔹 Layers: Conv1D(64,128,256) → Dense(64,32) → Dense(1)
  🔹 Parameters: 322,433
  🔹 Strength: Hierarchical feature learning

HYPERPARAMETER TUNING:
=====================

Full grid search via hyperparameter_tuning.py:
    $ python hyperparameter_tuning.py

CNN grid (48 configs): kernel (3,5) × pool (2,4) × dropout (0.2,0.4) × batch (8,16,32) × epochs (50,100)
LSTM grid (72 configs): dropout (0.2,0.4) × dense_units (16,32,64) × lr (0.001,0.005) × batch (8,16,32) × epochs (50,100)

Results saved to: results/CNN/SP500/ and results/LSTM/SP500/

Evaluate best models:
    $ python evaluate_best_models.py
