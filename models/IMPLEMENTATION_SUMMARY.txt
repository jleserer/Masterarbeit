===============================================================================
HYPERPARAMETER CHOICES
===============================================================================

COMMON PARAMETERS:
  - Lookback Window: 30 (1 month trading days)
  - Batch Size: 32
  - Epochs: 100 (with Early Stopping)
  - Learning Rate: 0.001 (Adam optimizer)
  - Dropout Rate: 0.2
  - Loss: MSE (mean squared error)
  - Metrics: MAE (mean absolute error)

CALLBACKS:
  - EarlyStopping: monitor='val_loss', patience=10
  - ReduceLROnPlateau: factor=0.5, patience=5, min_lr=1e-6

LSTM SPECIFIC:
  - Units: [128, 64] (stacked, progressively decreasing)
  - Dense units: 32
  - Strategy: Capture temporal dependencies

CNN SPECIFIC:
  - Filters: [64, 128, 256] (stacked, progressively increasing)
  - Kernel size: 5 (local feature detection)
  - Max pooling: 2 (feature abstraction)
  - Strategy: Hierarchical feature learning

INVERSE TRANSFORM:
  - All predictions are inverse-transformed to original price scale
  - Applied to all 3 features (Close, High, Low)
  - Uses fitted MinMaxScaler from training data

===============================================================================
DATA SPLIT REFERENCE
===============================================================================

Source: Goodfellow, I., Bengio, Y., & Courville, A. (2016). 
"Deep Learning". MIT Press.

Standard practice for train-val-test split: 65%-15%-20%

Rationale:
  - 65% training: Sufficient data for model learning
  - 15% validation: Hyperparameter tuning & early stopping
  - 20% test: Independent performance evaluation

Sequential split preferred for time series:
  - Respects temporal ordering
  - Avoids look-ahead bias
  - Realistic scenario simulation
